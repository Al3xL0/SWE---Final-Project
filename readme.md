# How to start 

create a virtual env : 

``` 
    py -m venv .venv
    
    .venv/Scripts/activate
``` 

## Installing Vizard

Vizard is Basilisk's 3D visualization application. It is a separate download from the Python packages in `requirements.txt`.

1. Open the [official Vizard download page](http://hanspeterschaub.info/basilisk/Vizard/VizardDownload.html).
2. Download the Vizard archive for your operating system (Windows, macOS, or Linux) and extract it.
3. Launch the Vizard application from the extracted files.
4. Run a Basilisk scenario that enables Vizard visualization, such as `scenarioBasicOrbit.py`. The simulation can then connect to Vizard to display the results.

The official download page also provides optional asset bundles for additional models; these are not needed for basic visualization.
